## 11. Important inconsistencies to resolve before rebuilding

1. The site name is presented as Kagum Academy, while the company name is Kagum Advance Sdn. Bhd. and the footer says Kagum Advance Group Sdn Bhd.
2. The site says “eight pillars” in some text, but nine Training Provider categories are currently visible.
3. The Kagum Academy service URL `/copy-of-hrdc-training` displays an Educational Consultant heading.
4. Several service/course pages reuse the same digital marketing welcome message.
5. The homepage reports 2,500+ trained participants, while the digital marketing page uses a different set of impact metrics.
6. The Artificial Intelligence page spells “Artificial” as “Artifical”.
7. The site uses both “HRDC” and “HRD Corp” terminology; this should be standardised.
8. Several older URLs contain “copy-of”, suggesting the navigation and URLs were created from duplicated Wix pages.
9. The exact Akademi Prosilat destination from the old Wix menu needs confirmation.
10. Package details for Silver, Bronze, 20-post and 30-post tabs should be manually verified before publishing prices locally.
